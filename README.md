# Yahoo!ファイナンス リアルタイム株価分析Webアプリケーション

Yahoo!ファイナンスから株価データと掲示板コメントをリアルタイムで取得し、本格的な投資判断を支援するWebアプリケーションです。

## 機能一覧

### リアルタイムデータ取得
- yfinanceによる株価データ取得（リアルタイム・履歴）
- Yahoo!ファイナンス掲示板のコメント取得
- 自動更新間隔: 30秒/1分/5分（設定可能）

### テクニカル分析
- 移動平均線（5日/25日/75日/200日）
- ボリンジャーバンド
- MACD、RSI、ストキャスティクス
- 一目均衡表
- 出来高分析
- ゴールデンクロス/デッドクロス自動検出
- サポート・レジスタンスライン自動検出

### ファンダメンタル分析
- PER、PBR、ROE、ROA
- 配当利回り、純利益率
- D/Eレシオ（財務健全性）
- 売上成長率
- 各指標の自動評価

### センチメント分析
- 掲示板コメントの感情スコア分析
- ポジティブ/ネガティブ/中立の分類
- キーワード抽出
- ワードクラウド生成

### AI予測
- 株価予測（10営業日先、信頼区間付き）
- トレンド分類（上昇/下降/横ばい、Random Forest）
- ボラティリティ予測（EWMAモデル）

### リスク評価
- ヒストリカルボラティリティ
- 最大ドローダウン
- VaR（Value at Risk、95%信頼水準）
- ベータ値（対日経225）
- シャープレシオ

### 投資判断エンジン
- テクニカル/ファンダメンタル/センチメント/AI/リスクを総合評価
- 買い/売り/中立の自動判定
- エントリー・エグジットポイント提案

### その他
- 銘柄比較ページ
- お気に入り銘柄管理
- 価格アラート
- ダークテーマUI

## インストール

```bash
pip install -r requirements.txt
```

## 使い方

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 にアクセスしてください。

### 基本操作
1. サイドバーで銘柄コード（例: 7203）を入力
2. チャート期間・更新間隔を設定
3. 各タブで詳細な分析を確認
   - テクニカル指標
   - ファンダメンタル
   - センチメント
   - AI予測
   - リスク評価

### CLI（従来機能）
```bash
python main.py stock 7203
python main.py board 7203
```

## トラブルシューティング

### データが取得できない
- インターネット接続を確認してください
- yfinanceのAPIが一時的に利用できない場合があります
- 銘柄コードが正しいか確認してください（日本株は4桁の数字）

### チャートが表示されない
- 取引時間外は最新データが更新されない場合があります
- ブラウザのキャッシュをクリアしてみてください

### 予測モデルのエラー
- 十分な履歴データ（3ヶ月以上）が必要です
- チャート期間を「1年」以上に設定してください
